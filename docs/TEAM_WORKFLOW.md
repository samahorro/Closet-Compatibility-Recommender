# Team workflow

1. Each member works in their own branch (`feature/data-pipeline`, `feature/compatibility-model`, `feature/outfit-search`, `feature/streamlit-ui`).
2. Keep `main` working; open a pull request for changes.
3. Agree on item feature fields and an item-pair scoring interface.
4. Keep datasets, model files and secrets out of Git.
5. Preserve the Polyvore disjoint train/validation/test split.
